Free menu bar app for macOS

Why is your Mac sweating?

MacSweat lives in your menu bar and shows, in one click, what’s heating up or slowing down your Mac — so you can close it yourself.

Install with one line in Terminal

curl -fsSL https://macsweat.parthh.dev/install | sh

macOS 13+ · Apple silicon & Intel · Free & open source

What it shows

The answer first, then the details.

Click the drop in your menu bar. MacSweat tells you what’s going on in a sentence, then shows you exactly what’s responsible.

  • Lives in your menu bar

    A small drop icon next to your live CPU %. One click opens the panel. Turn on Open at Login and it’s there whenever your Mac is.

  • A verdict in one line

    A status dot and a plain sentence that names what’s using the most:

    Your Mac is working hard — Next.js dev server is using the most CPU (386%).

    • Green
    • Orange
    • Red

  • CPU, memory and heat

    • CPUWith a few-minute history line
    • Memory usedThe same figure as Activity Monitor
    • Memory pressurePlus swap
    • HeatThe macOS thermal state

    When Heat says Hot, macOS slows the processor down to cool off — that’s the moment to look.

  • Background tasks you forgot

    Dev servers and scripts — Node.js, Next.js, Vite, Python, PostgreSQL and more — grouped by project folder. See how long each has been running and which app started it, or whether it’s been left running on its own.

  • Apps, not helper soup

    Sorted by CPU or memory. Chrome’s 25 helpers count as Chrome, WebKit pages count under Safari, and macOS services get plain names:

    • Spotlight indexing
    • iCloud sync

    Browsers show as one row, with a tip for finding heavy tabs in Chrome’s Task Manager.

  • You decide what closes

    Hover a row for Quit or Stop. Quit closes an app normally, just like choosing Quit, so it may ask you to save. Stop sends a dev task the same signal as Control-C.

    Both ask first. Nothing is ever closed automatically.

Privacy

Private by design

MacSweat reads everything it shows right on your Mac.

  • Everything is read on your Mac. CPU, memory, heat and the process list never need a server.
  • No account, no analytics, no tracking. Open it and it works.
  • One optional network request. The “Check for Updates…” menu item asks GitHub for the latest version. That’s the only request MacSweat makes.

Light on resources

A monitor shouldn’t be the thing slowing you down. MacSweat checks less often when you’re not looking.

3 s
Refresh rate while the panel is open
5 s
Overall numbers, while the panel is closed
30 s

Get started

Install, update, uninstall

Open Terminal, paste a command and press Return. The installer downloads the latest release from GitHub, checks its SHA-256 checksum, installs MacSweat to /Applications and opens it.

  • Install

    Downloads, verifies and opens MacSweat.

    curl -fsSL https://macsweat.parthh.dev/install | sh

  • Update

    Run the same command again.

    curl -fsSL https://macsweat.parthh.dev/install | sh

  • Uninstall

    Removes MacSweat.

    curl -fsSL https://macsweat.parthh.dev/uninstall | sh

Why a Terminal command?

MacSweat is free and isn’t notarized by Apple — that costs $99 a year — so macOS would block a download from your browser. The install script is short and readable.
